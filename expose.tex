\section{Introduction}
% Limit: 150 words
% Actual: 299 words

Hardware designs are getting more complex and diverse as fabrication technology
evolves and specialized solutions offer a competitive advantage.
This complexity must be handled by the design tools as well as the verification
flow.
Due to the increasing complexity and the associated costs, a correct design is
critical.
With that, design verification is crucial and also ubiquitous, making it a
critical component in the hardware design process.

One approach to ensuring correct behavior is to specify expected signal
sequences and verify that the design achieves a particular state following
these sequences, as illustrated in Figure \ref{fig:sequences}.
A linear sequence of events can be expressed with concurrent \gls{sva}, which
are fundamentally based on \gls{ltl}.
Concurrent \glspl{sva} are widely supported in proprietary industry tools, but
support in the open-source semiconductor ecosystem is limited.
As open-source hardware design projects are a major user of the open-source
tooling, limited support for verification negatively impacts the quality of
designs and adoption of the tools.
Additionally, it prevents research in the area of temporal logic for
verification, analysis and optimization for hardware designs.

A project which offers a framework for hardware designs and basic support for
SystemVerilog is \gls{circt} \cite{eldridgeMLIRHardwareCompiler2021}.
\gls{circt} builds on top of \gls{mlir} \cite{lattnerMLIRScalingCompiler2021}
and allows to have different levels of abstraction of components of the design
at the same time.
An advantage of \gls{circt}'s design is the modularity based on a variety of dialects
and transformation passes, which allows for different input and output formats.
An overview of \gls{circt} and the planned extensions is shown in Figure
\ref{fig:toolOverview}.

In this work, \gls{circt} will be extended to support linear temporal logic for
multiple input formats.
In order to make use of the verification for consuming tools, different
transformation methods will be investigated.
Research will focus on representation formats and abstractions for temporal
logic, with the goal of leveraging this verification information to improve the
integrated circuit design process itself.

\section{Related Work}
% related work and state of the art
% Overview of relevant approaches and detailing most similar solutions

% Limit: 300 words

\gls{circt} is actively developed and already has contributions related to this work.
An approach for temporal logic \cite{pnueliTemporalLogicPrograms1977} in \gls{circt}
is introduced in \cite{dobisFormalVerificationHardware2024}, with the \gls{ltl}
dialect and allows to specify the properties in Chisel
\cite{bachrachChiselConstructingHardware2012}.
Chisel is a hardware construction language, which also produces SystemVerilog
\cite{IEEEStandardSystemVerilog2024} code as an exchange format for other
tools.

\glspl{sva} are widely used in the industry
\cite{witharanaSurveyAssertionbasedHardware2022}, but the support in
open-source tools is limited.
A widely used open-source tool for synthesis is Yosys \cite{yosys}, which only
has full \gls{sva} support in conjunction with the proprietary
tool Verific \cite{verific2025}, the open-source SystemVerilog front-end only
supports immediate assertions and can not handle temporal logic.

The importance of \gls{sva}, which offer a powerful verification
method to describe the intended behavior of the design, can also be seen by the
research in generating \gls{sva} based on different input
vectors.
This includes tools for module interface verification
\cite{orenes-veraAutoSVADemocratizingFormal2021}, and recently builds on large
language models for general verification
\cite{keszoczeChatbotbasedAssertionGeneration2019,
sunImprovingVerificationProductivity2023} and specialized tests
\cite{kandeSecurityAssertionsLarge2024}.

Traditionally, temporal logic is used in simulation
\cite{habibiExtensionSystemCSystemVerilog2004, dahanCombiningSystemLevel2005},
but there are also efforts to utilized the assertions in emulation and related
to this the required transformations \cite{cimattiSymbolicCompilationPSL2008,
ehlersSymbolicBoundedSynthesis2010, noureddineSynthesisSequentialExtended2014}.
For a system emulation with the help of a \gls{fpga}, this typically relies of
transforming the statements to synthesizable hardware and the creation of a
checker monitor as shown in
\cite{kastelanSynthesizableSystemVerilogAssertions2009}.
\cite{bouleEfficientAutomataBasedAssertionChecker2007} demonstrates an
efficient automata transformations by focusing on \gls{sere}, the language used to
represent the logic statements in \gls{sva} and shows the
overhead for different examples when targeting \glspl{fpga}.

Beyond the traditional usage of assertions and temporal logic, research shows
how additional purposes can be realized.
An example which does not rely on assertions, but extracts timing information
by analyzing \gls{fsm}, makes use of the insights to detect leakage
of secrets \cite{reimannQTFlowQuantitativeTimingSensitive2024}.
In order to estimate the system power consumption
\cite{ahujaAssertionBasedModalPower2007} divides the system into different
operation modes, based on descriptions given in assertion properties.
Both examples demonstrate how timing information, derived or explicitly
defined, can be utilized for analytical purposes beyond traditional
verification objectives.

\section{Thesis Objective}

% Limit: 150 words
% Actual: 180 words

% TODO Reformulate this
The support of linear temporal logic as a method, and \gls{sva}
in general is only partially available in open-source hardware design tools.
With this comes a lack of transformation to analogous representations which can
be consumed by other tools.
As there is also no available environment in which a hardware design is
represented in conjunction with the temporal properties, no research is
possible in the area of hardware design analysis and optimization based on
signal sequences.

This thesis focuses on the benefits of temporal logic for hardware designs in
open-source design tools.

To achieve this goal, the following main research questions must be addressed:

\begin{itemize}
  \item How can linear temporal logic be represented in a multi-level
    intermediate representation?
  \item How must transformation methods be designed in order to propagate the
    user-specified verifications to later stages in the tool flow?
  \item Which insights can be gained from the specified properties and
    sequences?
\end{itemize}

With this thesis, a basis for more capable verification of hardware designs
will be created, as well as a first look into ways to make further use of
verification specifications.

The research will be structured into two topics.
The first part will lead to a suitable representation of the temporal
descriptions as a dialect in \gls{circt}, while the second part will focus on making
use of the new representations to find improvements for the hardware design.

In order to consume the \gls{sva}, the SystemVerilog support of \gls{circt}
must be extended.
The lexing, parsing and a first elaboration of the SystemVerilog description is
handled by Slang, a separate project, which comes with a high language feature
completeness for SystemVerilog, while providing programmatic methods to extract
information from the generated \gls{ast}.
With the design represented in the \gls{ast}, a translation into \gls{circt}'s
dialects follows.
A suitable representation and dialect translation path for \glspl{sva} must be
found.
A subset of \glspl{sva} may be selected to be supported in the first step, in
order to ensure progress.
% state explosion possible?
Dialect transformations, if possible and realizable, for different output
variants will provide new benefits for later stage tools.
The transformations might require additional dialects in order to represent
different forms of matching sequences and condition verifiers.
In this stage, research will focus on finding an optimal representation of the
temporal logic.

With the new dialect available, research will shift to utilize the added
information.
One possibility of extracting new insights lies in the analysis of the logic
elements described by the temporal properties.
For this a relation between the verification and the design has to be found,
together with a way of annotating the findings as well as how this can be used
by other tools.
Another possibility may be in design optimization.
Again, based on the temporal properties, which provide additional information
for the signals, an optimization might be possible on the utilized cells and
the connections between them.
The optimization might be possible at different levels of abstraction of the hardware.
Combining the optimization with the temporal logic dialect will provide
feedback on the suitability of the representation formulated in the first part
of the research project.

The research merits a Dr.-Ing. degree through two contributions to electronic
design automation for integrated circuits.
First, it advances verification methodology in hardware design by extending a
multi-level hardware representation with an abstracted temporal logic
representation, while building an improved framework for verification in the
open-source hardware ecosystem, enabling a higher correctness of hardware
designs.
Second, the research explores how verification specification of temporal logic
can be utilized in the design process, in contrast to only forwarding it to
tools later in the design flow, gaining additional insights into the design.
