\section{Introduction}
% Limit: 150 words
% Actual: 222 words

Hardware designs are increasingly complex due to advances in fabrication
technology and larger systems resulting in higher costs in both the
design and fabrication phases.
To ensure correctness of the design, verification is crucial.
Design and verification tools need to handle the increased complexity and
provide more capable methods.

One method to ensure correct behavior is to specify expected signal sequences
and verify that the design exhibits expected states following these
sequences, as illustrated in Figure \ref{fig:sequences}.
Concurrent \glspl{sva}, fundamentally based on \gls{ltl}, provide a powerful
way to express such temporal properties.
While \gls{sva} is widely supported in proprietary industry tools, support
in the open-source semiconductor ecosystem is limited, negatively impacting
design quality and tool adoption.
This limitation also prevents research in temporal logic for hardware
verification, analysis and optimization, as there are no common tools available
to build upon.

\gls{circt} \cite{eldridgeMLIRHardwareCompiler2021} offers a framework for
hardware designs with basic SystemVerilog support.
Building on \gls{mlir} \cite{lattnerMLIRScalingCompiler2021}, \gls{circt}
enables multi-level abstractions and provides modular transformation passes for
different input and output formats.
An overview of \gls{circt} and the planned extensions is shown in Figure
\ref{fig:toolOverview}.

This work extends \gls{circt} to support linear temporal logic across multiple
input formats and investigates transformation methods to make verification
properties accessible to downstream tools.
Research focuses on temporal logic abstractions to leverage verification
information for improving the integrated circuit design process.

\section{Related Work}
% related work and state of the art
% Overview of relevant approaches and detailing most similar solutions

% Limit: 300 words

\gls{circt} is actively developed and already has contributions related to this work.
An approach for temporal logic \cite{pnueliTemporalLogicPrograms1977} in \gls{circt}
is introduced in \cite{dobisFormalVerificationHardware2024} with the \gls{ltl}
dialect and allows to specify the properties in Chisel
\cite{bachrachChiselConstructingHardware2012}.
Chisel is a hardware construction language, which uses \gls{circt} to generate
SystemVerilog \cite{IEEEStandardSystemVerilog2024} code as an exchange format
for other tools.

\glspl{sva} are widely used in the industry
\cite{witharanaSurveyAssertionbasedHardware2022}, but the support in the
open-source ecosystem is limited.
A widely used open-source tool for synthesis is Yosys \cite{yosys}, which only
has full \gls{sva} support in combination with the proprietary
tool Verific \cite{verific2025}.
The open-source SystemVerilog front-end only supports immediate assertions and
can not handle temporal logic.

The importance of \gls{sva}, which offer a powerful verification
method to describe the intended behavior of the design, can also be seen by the
research in generating \gls{sva} based on different input
vectors.
This includes tools for module interface verification
\cite{orenes-veraAutoSVADemocratizingFormal2021}, and recently builds on large
language models for general verification
\cite{keszoczeChatbotbasedAssertionGeneration2019,
sunImprovingVerificationProductivity2023} and specialized tests
\cite{kandeSecurityAssertionsLarge2024}.

Traditionally, temporal logic is used in simulation
\cite{habibiExtensionSystemCSystemVerilog2004, dahanCombiningSystemLevel2005},
but there are also efforts to utilize the assertions in emulation which require
transformations \cite{cimattiSymbolicCompilationPSL2008,
ehlersSymbolicBoundedSynthesis2010, noureddineSynthesisSequentialExtended2014}.
For a system emulation with a \gls{fpga}, this typically relies on transforming
the statements to synthesizable hardware and the creation of a checker monitor
as shown in \cite{kastelanSynthesizableSystemVerilogAssertions2009}.
\cite{bouleEfficientAutomataBasedAssertionChecker2007} demonstrates an
efficient automata transformation by focusing on \gls{sere}, the language used to
represent the logic statements in \gls{sva} and shows the
overhead for different examples when targeting \glspl{fpga}.

Beyond the traditional usage of assertions and temporal logic, research shows
how additional benefits can be realized.
An example that does not rely on assertions, but extracts timing information
by analyzing \gls{fsm}, makes use of the insights to detect leakage
of secrets \cite{reimannQTFlowQuantitativeTimingSensitive2024}.
In order to estimate system power consumption,
\cite{ahujaAssertionBasedModalPower2007} divides the system into different
operation modes, based on descriptions given in assertion properties.
Both examples demonstrate how timing information, derived or explicitly
defined, can be utilized for analytical purposes beyond traditional
verification objectives.

\section{Thesis Objective}
% Based on the related work, show the research gap addressed in the thesis
% Research questions the thesis will answer
% Describe the overall expected outcome of your research.

% Limit: 150 words
% Actual: 180 words

Support for linear temporal logic and \gls{sva} is only partially available
in open-source hardware design tools.
Without an environment where hardware designs are represented alongside
temporal properties, research in hardware design analysis and optimization
based on signal sequences is not possible.

This thesis focuses on enabling temporal logic benefits for hardware designs in
open-source design tools.

To achieve this goal, the following main research questions must be addressed:

\begin{enumerate}
  \item How can linear temporal logic be represented in a multi-level
    intermediate representation?
  \item How must transformation methods be designed in order to propagate the
    user-specified verifications to later stages in the tool flow?
  \item Which insights can be gained from the specified properties and
    sequences?
\end{enumerate}

With this thesis, a basis for more capable verification of hardware designs
will be created, as well as a first look into ways to make further use of
verification specifications.

The research is structured into two phases: developing a suitable temporal
logic representation within \gls{circt}'s dialect framework, followed by
leveraging these representations for hardware design optimization and analysis.

In order to consume \glspl{sva}, the SystemVerilog support of \gls{circt} must
be extended.
The lexing, parsing and elaboration of the SystemVerilog description is handled
by Slang, a separate project, which comes with a high language feature
completeness for SystemVerilog, while providing programmatic methods to extract
information from the generated \gls{ast}.
With the design represented in the \gls{ast}, a translation into \gls{circt}'s
dialects follows.
A suitable representation and dialect translation path for \glspl{sva} must be
found; an example of different representations is shown in Figure
\ref{fig:dialectAbstraction}.
Dialect transformations, if possible, for different output variants will
provide new benefits for later stage tools.
As shown in Figure \ref{fig:svaTransformations}, the temporal representation
can be used for different purposes, but the transformations might require
additional dialects and passes to represent the different forms.
In this stage, research will focus on finding an optimal representation of the
temporal logic.

Following the formulation of the dialect and passes, the second phase
investigates the utilization of the newly added information.
A potential use case is the analysis of the design based on the verification
statements.
A relation between the temporal properties and the design structures is
established and stored with annotations to pass it along to other tools.
Another possibility is design optimization.
Again, based on the temporal properties, an optimization might be possible on
the utilized cells and the connections between them, making use of different
abstraction levels to leverage various design specifications.
Combining the optimization with the temporal logic dialect will provide
feedback on the suitability of the representation found in the first phase.

The research merits a Dr.-Ing. degree through two contributions to electronic
design automation for integrated circuits.
First, it advances verification methodology in hardware design by extending a
multi-level hardware representation with an abstracted temporal logic
representation, while building an improved framework for verification in the
open-source hardware ecosystem, enabling a higher correctness of hardware
designs.
Second, the research explores how verification specification of temporal logic
can be utilized in the design process, in contrast to only forwarding it to
tools later in the design flow, gaining additional insights into the design.
